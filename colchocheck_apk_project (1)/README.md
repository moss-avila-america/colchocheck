# ColchoCheck — Guía de Compilación Gratuita en GitHub (Mac)

## ¿Por qué no veía la carpeta `.github` en Finder de Mac?
En macOS, cualquier carpeta que empieza con un punto (como `.github`) se oculta automáticamente por el sistema operativo.
- **Atajo en Mac:** Presiona **`Cmd + Shift + .`** (Comando + Shift + Punto) dentro de la carpeta en Finder y verás aparecer inmediatamente la carpeta `.github/workflows/build_apk.yml`.
- **Respaldo visible:** También incluimos una copia visible llamada `workflow_github_para_copiar/build_apk.yml` por si deseas abrirlo o revisarlo directamente.

## Cómo subirlo a GitHub y descargar tu archivo `.apk` gratis
1. Entra a [github.com](https://github.com) y crea un repositorio nuevo **Public** llamado `colchocheck`.
2. Haz clic en **"uploading an existing file"**.
3. En tu ventana de Finder en la Mac, presiona **`Cmd + Shift + .`** para ver la carpeta `.github`, selecciona todos los elementos (`.github`, `lib`, `supabase`, `pubspec.yaml`, `README.md`) y arrástralos a la página de GitHub.
4. Presiona el botón verde **Commit changes**.
5. Ve a la pestaña **Actions** arriba en tu repositorio de GitHub y en 4 minutos podrás descargar **`ColchoCheck-Instalador-APK`** con tu archivo `.apk` listo para instalar en Android.
